## Exact NTD

[ExactNTD]() (Exact Nonnegative Tensor Decomposition) is a repository of verifiable uniqueness certificates, built using the algorithm proposed in [1]. It covers high-profile published datasets for nonnegative tensor decomposition from multiple fields.
